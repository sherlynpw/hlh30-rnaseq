# DEG Venn diagrams — WT vs *hlh-30(tm1978)*, per developmental transition

Four area-proportional Venn diagrams, one per transition, comparing the set of
**DEGs in wild type** with the set of **DEGs in *hlh-30(tm1978)*** for that same
developmental change. Exclusive regions and the overlap are split into **Up** and
**Down**.

Generated by `venn-degs.R`. Circle **areas are proportional to set sizes** and the
overlap area is solved analytically (two circles → exact), so the picture is
honest: e.g. L1→L4 is almost fully shared, D3→D6 barely overlaps.

## Two versions are provided

The only difference is **what the overlap (middle) region counts as "shared".**

| Folder | Overlap = | Use |
|---|---|---|
| `shared/` | **concordant shared only** — genes DE in both genotypes *and* with a similar fold change (\|Δlog2FC\| < 1). Matches the compare-DE `shared` category and your draft's "Shared" numbers. A small grey `(+N diff.)` note shows how many genes were set aside. | Faithful to the original draft. |
| `intersection/` | **every gene DE in both genotypes** (concordant shared **+** "differential"). This is the strict set-theoretic intersection of the two DEG circles. | Correct if you want the overlap to literally mean "in both circles". |

**"Differential" genes** are DE in *both* genotypes but respond with a
*substantially different magnitude* between them (\|log2FC_WT − log2FC_mut\| ≥ 1).
They are real members of both DEG sets, so they belong in the overlap of a strict
set Venn — that is why `intersection` > `shared` by exactly the differential count.

## Splitting the shared region Up/Down (the question you asked)

**No extra analysis was needed.** Every overlap gene already has a log2FC in each
genotype. Shared genes are concordant by definition, so each is simply *up in both*
or *down in both* (0 genes go in opposite directions in the `shared` set). We just
read the sign of the WT log2FC.

## How every number was computed

1. **DEG per genotype per transition.** From the DESeq2 result table for each
   contrast, a gene is a DEG if `padj < 0.05` **and** `|log2FC| ≥ 1`.
2. **Orient "Up".** "Up" always means *higher at the later stage* of the
   transition. Some contrasts are stored in the reverse orientation; their log2FC
   sign is flipped first (see table below).
3. **Regions** (WT set = W, *hlh-30* set = M):
   - **WT-only** = W − M, split by WT log2FC sign → Down (`<0`) / Up (`>0`)
   - **hlh-30-only** = M − W, split by *hlh-30* log2FC sign
   - **overlap** = W ∩ M
     - `shared` = overlap genes with `|log2FC_WT − log2FC_M| < 1`
     - `differential` = overlap genes with `|log2FC_WT − log2FC_M| ≥ 1`
     - Up/Down of the overlap = sign of WT log2FC (concordant)

## Note vs the original draft

- **Panel A/L4→Day 3 Down/Up were transposed in the draft** (it read 704 Down /
  750 Up for WT). Recomputed consistently with the other panels it is **750 Down /
  704 Up** for WT and **204 Down / 203 Up** for *hlh-30*. Fixed here.
- All other draft numbers matched to within ±1 (boundary rounding at the padj /
  \|log2FC\|=1 cutoffs).
- The draft's "Shared" equals the `shared/` version here (differential genes were
  not shown); the `intersection/` version adds them back.

### L1 → L4 ±1 caveat

Panel A (L1→L4) differs from the draft by **exactly one gene** in the up/down
split (WT-only 715 vs 716 up; hlh-30-only 528/560 vs 529/559 — totals ~identical:
hlh-30-only is 1088 either way). This is the **only** transition with no pipeline
`compare_de` artifact (the compare-DE module was not run for `hlh30-all-ruv`), so
its counts are tallied ad hoc rather than read from pipeline gene lists — B/C/D
match the draft to the gene, L1→L4 does not have that anchor. The run also stores
only the `WT_L1_vs_WT_L4` orientation, so the WT axis is sign-reversed here.

The ±1 is a pure **threshold-boundary artifact**: ~158 WT (157 hlh-30) genes sit
within 0.02 of \|log2FC\|=1 and ~104 (129) within 0.005 of padj=0.05, so one gene
crossing a cutoff reshuffles one count. It is **not** explained by `>=` vs `>`,
`padj<` vs `<=`, shrunken vs MLE log2FC (MLE is further off: 710/566), or LFC
rounding — the values here use full-precision shrunken log2FC, \|log2FC\|>=1,
padj<0.05, consistent across all four panels. Biologically meaningless; to get
byte-identical L1→L4 numbers, match against the collaborator's own L1→L4 gene
lists.
